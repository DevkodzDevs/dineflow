# DineFlow audit — 11 October 2026

The "master product prompt" asked for an audit of what exists, a comparison with Petpooja, GoFrugal
and Restroworks, and then the highest-value safe improvements. This is that audit, and the record
of what was built from it on the same day (migration 0087, the **New menu** group). Everything in
the *status* columns was read from the code and migrations, not from memory; the competitor column
quotes their public pages and says when a claim could not be verified.

## 1 · What DineFlow actually is

| | |
| --- | --- |
| Framework | Next.js 15 (App Router, server actions), TypeScript, Tailwind v4, Framer Motion |
| Data | Supabase Postgres — 87 migrations, RLS on every tenant table, every write through a `security definer` RPC with a pinned `search_path` that checks the caller |

## 5 · Built today (migration 0087 + the New menu)

- **Audit trail** (`/audit`): `audit_events` written by triggers on bills, orders, order_items, payments, stock_ledger, menu_items, profiles, restaurants, shift/day closes, cash movements and purchase orders. Readable by owner/manager/supervisor; the API cannot insert, edit or delete rows.
- **Cash & controls** (`/controls`): cash in/out with reasons (`cash_move`), the drawer figure in `shift_expected`, shift-close history, this week's voids and cancellations with reasons and names.
- **Intelligence** (`/intelligence`): `menu_engineering()` (plate cost, margin, Star/Plowhorse/Puzzle/Dog), `exceptions_summary()` (discounts vs a 28-day baseline, voids, cancellations, cash variances), `day_compare()` (yesterday vs the same weekday, today so far) and a sentence briefing built from them. Every line links to the screen it came from.
- **Void and cancel ask why**: `void_bill`, `cancel_order`, `cancel_line` with roles (a waiter may cancel a pending dish; a manager one the kitchen started; a cashier or manager a bill); the reason dialog with quick chips.
- **Printing**: station routing (`lib/print/route.ts`, 4 unit tests), drawer kick on cash.
- **Nav**: a "New menu" group in the sidebar and the phone's More sheet; no new modules in `role_modules` — each page checks the role itself.

Evidence: `dry87.cjs` 33/33 (rolled back), `newmenu.mjs` browser suite, lint 0 errors, 47/47 unit tests, build. See `docs/sections/controls-and-intelligence.md`.

## 7 · Pricing, against the evidence

Petpooja publishes no price; the only figures are third-party estimates (₹1,000–₹12,000/month, with a competitor's blog at the top of that range). GoFrugal states "from ₹500 per user per month". DineFlow's ₹2,499/month per property sits inside that band. The prompt's Starter ₹1,499 / Growth ₹2,999 / Business ₹4,999 is a reasonable ladder to test, but **the plan has no limits to enforce yet** — outlets, terminals, users and AI calls are not metered anywhere. Build the entitlements before advertising the tiers.
